12-Week Synchronized Execution Roadmap (Section 10 Alignment)

Step-by-step bi-weekly integration milestones across all 6 team members.

Phase 1 • Weeks 1–2 Foundation

Database Schema, RLS & Core Backend

Set up Docker Compose (Postgres 16 + pgvector, Redis, Meilisearch, MLflow). Each member writes Prisma migrations for their owned tables, configures Row-Level Security, loads AdventureWorks/Olist datasets, and builds core NestJS CRUD APIs.

Phase 2 • Weeks 3–4 Core Read Agent

LangGraph State Machine & Read Tools

Initialize LangGraph orchestrator. Implement safe Read-Only tools first: search_products (Adel), query_sales_data with sqlglot AST validation (Abdallah), and Store Policy RAG (Roaa).

Phase 3 • Weeks 5–6 Machine Learning

Forecasting, RFM, Stockout & FastAPI

Train and benchmark Prophet/LightGBM/SARIMA with SHAP (Retaj), K-Means RFM clustering (Renad), Stockout velocity predictor (Adel), and Revenue Anomaly detection (Abdallah). Expose all via FastAPI + MLflow.

Phase 4 • Weeks 7–8 Write Tools & HITL

Human-in-the-Loop & Audit Logging

Implement state-modifying tools using LangGraph interrupt_before: create_store_tenant (Moustafa), bulk_update_prices (Adel), create_promotion_for_segment (Renad), and immutable agent_actions logging + Langfuse (Roaa).

Phase 5 • Weeks 9–10 Generative UI

React.js Storefront & Streaming GenUI

Connect our React 18 + Vite client and streaming Generative UI registry so every member's tool streams interactive React components directly inside the chat window: Recharts, Diff Preview Cards, Live Storefront Preview, and Arabic/English RTL switcher.

Phase 6 • Weeks 11–12 Evaluation & Defense

Benchmarking, Stress Testing & Thesis

Execute the 100-prompt Evaluation Benchmark (Tool Selection F1, Text-to-SQL Execution Accuracy, Forecast WAPE/MAE, Prompt Injection Block Rate), finalize graduation book, and rehearse live demo.
